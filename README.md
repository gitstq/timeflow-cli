# 🕐 TimeFlow CLI

智能命令行时间追踪工具 | A smart command-line time tracking tool with Pomodoro support

## ✨ Features

- ⏱️ Simple time tracking for tasks
- 🍅 Pomodoro technique support
- 📊 Daily and weekly reports
- 📁 Project and category management
- 📤 Export to JSON, CSV, and Markdown

## 🚀 Quick Start

```bash
# Install
pip install timeflow-cli

# Start tracking
timeflow start "My Task" --project myproject

# Check status
timeflow status

# Stop tracking
timeflow stop

# View today's report
timeflow report today
```
